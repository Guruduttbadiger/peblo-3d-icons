# Import Peblo icons into Figma

1. Download the repository ZIP from GitHub using **Code → Download ZIP** and extract it.
2. Open the category you need under `icons/`.
3. Drag the individual transparent PNG files into your Figma canvas, or use **Place image**.
4. Scale each image proportionally to the size required by your interface.

The original PNG files preserve their native resolution and transparency. Contact sheets are previews; use the individual PNGs in your designs.
