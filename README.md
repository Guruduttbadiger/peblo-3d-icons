# Peblo 3D Icons

972 unique matte ceramic 3D icons, organized into 12 categories. Every original is a **1254 × 1254 transparent PNG**.

Designed in muted coral, warm cream and deep teal, with rounded forms and a consistent elevated three-quarter view.

**All 972 original PNG files are published.** Check `manifest.json` for the exact published files.

## Use in Figma

Download this repository with **Code → Download ZIP**, extract it, then drag the individual PNG files from `icons/` onto your Figma canvas. Keep the aspect ratio when resizing. See [Figma import instructions](docs/figma-import.md).

## Files and progress

`manifest.json` lists each published icon’s stable ID, concept, category, dimensions, revision, SHA256 and Git blob hash. `previews/` contains contact sheets; use the individual PNGs for production.

The collection is growing toward 3,000 unique icons. New checked originals are added in reviewed batches.
